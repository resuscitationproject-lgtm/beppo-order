# Beppo mobile order\n\nCloudflare Workers + D1 + Static Assets + LINE Messaging APIで運用するBeppo向けモバイルオーダーです。\n\n## 現行構成\n\n新しい実装は [cloudflare/](cloudflare/) 配下です。\n\n- 顧客向けHTML注文画面\n- iPad向けadmin画面\n- 開店前レジ金確認\n- 商品価格・原価履歴管理\n- 注文時点の原価スナップショット\n- 日計・週計CSV（売上・原価・粗利）\n- Cloudflare D1による注文・在庫・受取枠管理\n- LINE Messaging APIによる店舗通知\n\n## 開発\n\n    cd cloudflare\n    npm test\n    wrangler d1 migrations apply beppo-db --local\n    wrangler dev\n\n公開前に `cloudflare/wrangler.jsonc` のD1 `database_id`を設定し、`ADMIN_TOKEN`、`LINE_CHANNEL_ACCESS_TOKEN`、`LINE_STORE_USER_ID`をCloudflare Secretsへ登録します。\n\n売上集計は受取完了した注文を対象に、受取日基準で行います。原価は注文時点の値を明細へ保存するため、後日の原価変更で過去の粗利は変わりません。\n\n## 旧実装\n\n旧Spreadsheet/GAS版は移行期間の参照用としてルートに残しています。新規開発・運用は `cloudflare/` を使用します。\n
